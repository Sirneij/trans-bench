trans-bench runs one transitive-closure query on SQL, NoSQL and NewSQL databases and on the logic system XSB, over fourteen kinds of graph. Every result is compared with a closure computed independently, so a fast answer that is wrong is reported as wrong.

How it works

How a closure grows

    Verification

    Every answer is checked

    A run counts only if its result has the same number of pairs and the same 64-bit hash as the closure computed in Python. Wrong results are kept and marked, because a database that returns an incomplete closure without an error is a finding in itself.

    Harness

    The same engine for the site and the command line

    A campaign started from this site, from transitive.py or from benchmark.py goes through engine/campaign.py. Each run is a separate process with a time limit, and its record is appended to runs.jsonl.
