Create Query Domain

A query domain defines a category of recursive queries (e.g., shortest_path, reachability_with_avoidance). You can benchmark multiple domains across the same systems and graphs.

Used as directory name: domains/<name>/
Choose a template to get started. You'll customize it next.
Cancel

What happens next?

1
A directory domains/<name>/ is created with a descriptor.yaml.
2
The descriptor defines query parameters, output schema, and supported execution modes.
3
You'll add rule files to each system: systems/*/rules/{domain}_{mode}.sql
4
Run experiments: python transitive.py --domains {domain}
